Key Hardware Advantage:

Fibonacci Search uses only additions and subtractions to calculate probe indices, eliminating division (costly on RISC processors) unlike Binary Search. It also provides superior memory locality on non-uniform storage media.

What is Fibonacci Search?

"Fibonacci Search is an efficient comparison-based searching algorithm that works on a sorted array. It uses Fibonacci numbers to divide the search space instead of using the exact middle element like Binary Search."

While Binary Search splits an array strictly in half (1/2 and 1/2), Fibonacci Search partitions the search interval into two sub-intervals with lengths corresponding to consecutive Fibonacci numbers (Fm-2 and Fm-1). This produces a split ratio close to the golden ratio (φ ≈ 0.618).

How the Algorithm Works (Step-by-Step)

  1. Generate Fibonacci numbers: Find the smallest Fm ≥ n (array size). Set fibM = Fm, fib1 = Fm-1, fib2 = Fm-2.
  2. Initialize offset: Set offset = -1 (marks eliminated items on the left).
  3. Select probe index: Calculate i = min(offset + fib2, n - 1).
  4. Compare probe with target:
    • If arr[i] < target: Target is to the right. Discard left subarray, set offset = i, and move Fibonacci numbers down by 1 rank (fibM = fib1, fib1 = fib2, fib2 = fibM - fib1).
    • If arr[i] > target: Target is to the left. Discard right subarray, keep offset, and move Fibonacci numbers down by 2 ranks (fibM = fib2, fib1 = fib1 - fib2, fib2 = fibM - fib1).
    • If arr[i] == target: Match found! Return index i.
  5. Boundary check: When fibM ≤ 1, if fib1 == 1 and arr[offset + 1] == target, return offset + 1. Otherwise return -1.

Fibonacci Search vs. Binary Search

Feature Fibonacci Search Binary Search
Array Requirement Sorted array Sorted array
Partition Technique Fibonacci numbers (Fm-2 and Fm-1) Divide by 2 (Middle element)
Average Time Complexity O(log n) O(log n)
Worst Time Complexity O(log n) (≈ 1.44 log2 n) O(log n) (log2 n)
Auxiliary Space O(1) O(1)
Operations Used Only Addition & Subtraction (+) / (-) Division or Bit Shift (/) / (>>)
Cache & Non-uniform Access Better for storage media with non-uniform access Jumps to center; uniform distribution
Core Idea Golden-ratio Fibonacci partitioning Equi-partition divide-and-conquer
